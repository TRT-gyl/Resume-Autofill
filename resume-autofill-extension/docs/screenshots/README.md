# 功能截图说明

本目录保存项目首页使用的界面截图。截图采用项目实际 HTML / CSS / JavaScript 界面与虚构演示资料，帮助读者了解功能和操作入口。

| 图片 | 展示内容 | 对应实现 |
| --- | --- | --- |
| `resume-editor.png` | 分类维护简历资料与多段经历 | `popup/popup.html`、`popup/popup.js` |
| `auto-fill.png` | 在演示招聘表单中执行本地填充并查看结果 | `content/content.js` |
| `ai-settings.png` | API 地址、密钥与模型的配置入口 | `popup/popup.html`、`popup/popup.js` |
| `input-recommendations.png` | 字段推荐、自动推荐开关与追加填写 | `content/content.js` |
| `application-records.png` | 投递记录、统计、筛选与待办 | `records/records.html`、`records/records.js` |

## 演示范围

- 姓名、联系方式、经历、学校、企业和岗位均为虚构演示资料，不包含维护者的真实简历、照片或投递记录。
- 截图中的资料仅供展示，开源版首次启动仍为空白资料，不会自动载入这些记录。
- 自动填充和输入框推荐在本地演示页面中展示，不代表所有招聘网站均已完成兼容性验证。
- AI 截图只展示配置入口；没有使用真实 API Key，没有执行真实模型请求，也不作为模型填充效果的证明。
- 投递记录中的状态和日期为演示数据，不对应真实企业招聘进度。

## 更新截图时

使用隔离的演示环境和虚构资料，保留项目实际界面，不嵌入个人浏览器账户、书签栏、真实网址参数或开发日志。更新后核对 README 的功能描述与当前界面一致，并检查图片可读性和隐私内容。

新增图片须同时满足发布隐私检查的允许范围；只将已人工复核的演示截图纳入版本管理。不要从个人使用环境直接截取并发布整屏图片。
